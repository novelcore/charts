📚 Next Steps:

To start using GitOps Promoter, you'll need to create:

1. **SCM Provider** - Configure your Git provider (GitHub, GitLab, etc.):
   ```yaml
   apiVersion: promoter.argoproj.io/v1alpha1
   kind: SCMProvider
   metadata:
     name: github-provider
     namespace: {{ include "gitops-promoter.namespace" . }}
   spec:
     github:
       domain: github.com
       tokenRef:
         secretName: github-token
         key: token
   ```

2. **Git Repository** - Define your GitOps repository:
   ```yaml
   apiVersion: promoter.argoproj.io/v1alpha1
   kind: GitRepository
   metadata:
     name: my-gitops-repo
     namespace: {{ include "gitops-promoter.namespace" . }}
   spec:
     url: https://github.com/your-org/gitops-repo
     scmProviderRef:
       name: github-provider
   ```

3. **Promotion Strategy** - Define how promotions work:
   ```yaml
   apiVersion: promoter.argoproj.io/v1alpha1
   kind: PromotionStrategy
   metadata:
     name: my-promotion-strategy
     namespace: {{ include "gitops-promoter.namespace" . }}
   spec:
     repository:
       name: my-gitops-repo
     environments:
     - name: staging
       branch: staging
     - name: production
       branch: main
   ```
